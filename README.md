# AI Product Card Generator (Тестовое задание)

Сервис на базе FastAPI, который принимает JSON с техническими характеристиками контрольно-измерительного прибора и генерирует черновик B2B-карточки товара (SEO-заголовок, описание, характеристики, ключевые слова и блок для менеджера) с помощью LLM.

## 🛠 Стек технологий

*   **Язык:** Python 3.10+
*   **Веб-фреймворк:** FastAPI + Uvicorn
*   **Валидация данных:** Pydantic
*   **Интеграция с LLM:** Библиотека `openai` (через OpenAI-совместимый API)
*   **LLM:** Локальная модель **Qwen 2.5 Coder 14B**, запущенная через **LM Studio**.
*   **Документация API:** Swagger UI (встроенный в FastAPI).

## ✨ Реализованный функционал

1.  **Прием данных:** Эндпоинт `POST /generate` принимает JSON с валидацией через Pydantic.
2.  **Строгий промпт-инжиниринг:** Системный промпт настроен так, чтобы **исключить галлюцинации**. Модели строго запрещено выдумывать характеристики, которых нет во входных данных.
3.  **JSON Mode:** Ответ от модели парсится как строгий JSON (с предварительной очисткой от markdown-разметки, которую иногда добавляют локальные модели).
4.  **Обработка ошибок:** Обрабатываются ошибки сети/API (возвращается понятный статус 500), а также невалидный JSON.
5.  **Удобный интерфейс:** Благодаря Swagger UI, сервис можно тестировать через веб-форму без написания дополнительного фронтенда.

    Ограничения и возможные улучшения

    Ограничение LM Studio: Локальный сервер LM Studio не поддерживает строгий параметр response_format={"type": "json_object"} (как это делают облачные провайдеры). Поэтому в коде реализован парсинг ответа с очисткой от возможных markdown-оберток (json ... ).

    Скорость: Локальная модель на потребительской видеокарте генерирует ответ за 10-15 секунд. Для продакшена с высокой нагрузкой лучше использовать vLLM для ускорения инференса, а также внедрить кэширование (Redis), чтобы не генерировать карточки для одинаковых приборов повторно.

    Валидация: В будущем можно добавить валидацию того, что LLM вернула строго те поля, которые мы ожидаем (сейчас Pydantic проверяет только входные данные, а на выход мы отдаем dict из JSON).
